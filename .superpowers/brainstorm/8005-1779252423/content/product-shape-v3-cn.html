GraphCast 气象预测原语

由已验证 OneScience 代码、模型资源和 ERA5 数据集资源共同生成。

领域：地球科学 类型：模型运行 状态：已验证
输入：时间范围、变量、区域、模型权重
输出：预测张量、指标、报告产物
约束：GPU/DCU 画像、数据格式、许可证
面向智能体的调用契约
调用原语({
  原语: "地球科学.GraphCast.气象预测",
  输入: { 起始时间, 预测时长, 变量列表 },
  运行环境: { 加速卡: "GPU" }
})
可被调用：weather-workflow、runtime、coder

推荐生命周期

✓

基础资源 -> 候选原语 -> 待审核 -> 已验证 -> 可调用

资源是广义目录项；原语必须补齐契约、适配器和验证样例后，才能开放给智能体和 OneSkills 调用。

产品不应把所有资源自动开放为原语，而是先给出候选原语建议，再通过契约和验证流程进入智能体注册表。
