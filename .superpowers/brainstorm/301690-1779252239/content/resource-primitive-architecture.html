Core Product Decision

Should AI primitives be a separate first-class asset type, or simply a generated view over resources?

Resources | Primitives | Agents
Primitive detail: contract, examples, source resources, callable endpoint

Recommended: First-class primitives

Resources are source materials; primitives are operational contracts agents can call.

Resources with Primitive Badges
Each resource card gets generated primitive metadata inline

Lightweight: Generated view

Faster to ship, but weak for lifecycle, validation, and reusable agent contracts.
